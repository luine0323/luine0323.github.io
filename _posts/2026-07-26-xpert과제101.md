
리눅스 기초 명령어

1.sudo apt update - apt 명령어로 설치가능한 소프트웨어 패키지목록 업데이트, 각 소프트웨어 패키지별로 어떤 버전 설치가능한지 업데이트

2.sudo apt upgrade - 리눅스에 설치된 소프트웨어 패키지 버전 업그레이드

3.id - 현재유저의 유저 id와 속해있는 그룹id 출력

4.pwd - 현재 작업중인 디렉토리 경로 출력

5.ls - list의 줄임말, 디렉토리 내용 출력, -l 플래그 추가시 더 자세한 내용출력

6.cd - change Directory 줄임말, 디렉토리 변경 명령어, 절대경로 - 루트디렉토리 /를 시작으로 모든 경로 
적어서 표현, 상대경로 - 현재 디렉토리를 기준으로 상위 또는 하위 디렉토리로 뻗어가는 경로, ~ 현재 유저 
홈 디렉토리 - 이전위치헀던 디렉토리

7. mkdir -  make Directory 줄임말 디렉토리 생성 명령어

8.touch - 비어있는 새로운 파일 생성

9.mv- move의 줄임말, 파일이나 디렉토리 위치 옮길떄 사용 명령어

10.rm - remove 의 줄임말, 파일이나 디렉토리 삭제, 디렉토리삭제는 -r을 추가한 rm -r로 수행

11. cat - 파일의 내용 출력, cat 파일경로 형식

12.file - 파일 유형 출력 명령어, file 파일경로 형식

13.echo - 셀에 유저가 입력한 텍스트 출력, echo를 이용해 파일생성도 가능 echo 명령문 끝에 >파일명을 이
어붙여 동작

14.cp - copy의 줄임말, 파일이나 디렉토리 복사 명령어

15.grep - 전체에서 특정 문자열 찾을떄 사용 , grep  문자열 형식

16.man - manual 의 줄임말, 특정 명령어의 매누얼을 보여주는 명령어 , 명령어 사용법, 옵션, 예제등 유용
한 정보 담음

17.curl - client url의 줄임말, 서버에 데이터를 보내거나 서버로부터 데이터를 받는 데이터 전송명령어, 
curl 옵션 url형식으로 사용하며 http,https,ftp등 다양한 프로토콜 지원, 

주요옵션은 -o file(전송 받은 데이터 파일에 저장),-i(결과값에 http 응답 헤더 포함), -x "method"(http 요
청 메소드 저장). -d "key=value" http post 메소드로 데이터 전송



와일드 카드 - 리눅스에서 임의의 다른 문자를 나타낼수 있는 특수 문자의미, 주로 명령어를 다른 문자열로 대
체하기 위해 사용 ?(a-z, 0-9 범위내의 임의 1개 문자로 대체) , *(a-z, 0-9 범위내의 임의 0개 이상 문자로 
대체) , [](범위 내의 모든 문자 대체)



리다이렉션 - 모니터에 나타나는 표준 출력 또는 키보드로 입력하는 표준입력을 다른곳으로 변경하는 작업, 주
로 어떤 명령어의 결과를 파일로 저장 혹은 다른명령어의 입력으로 전달되는 형태

명령어 >파일 - 명령어 표준출력을 파일로 변경, 없으면 새로 생성, 있다면 덮어씀

명령어 >>파일- 명령어 표준출력을 파일로 변경, 없다면 생성, 있다면 이어서 씀

명령어 < 파일 - 명령어 표준입력을 파일로 변경, 파일로부터 표준입력을 받아 명령어 수행

파이프 - 리다이렉션 한형태, 명령어 결과 표준출력을 다른 명령어의 표준입력으로 보낼때 사용, 파이프는 l문
자로 나타냄



권한 - 유저와 그룹 - 유저는 이름과 고유한 사용자 id(uid)를 가짐, 그룹은 여러유저가 속할수 있는 그룹 그
룹이름과 고유 그룹 id(uid)를 가짐

/etc/passwd는 리눅스 유저정보 담은 텍스트 파일, 사용자이름, id,속한 그룹 id등의 정보 포함, cat 
/etc/passwd로 내용 확인

/etc/group 리눅스 그룹정보 저장하는 텍스트 파일, 각그룹의 이름 , id, 그룹 속한 유저목록등의 정보 포함

파일 및 디렉토리 권한 - 각파일과 디렉토리는 소유자와 소유그룹을 가짐, 소유자는 파일또는 디렉토리의 권한
을 수정할 능력가짐, 소유자는 이를 통해 소유자또는 소유그룹에 포함된 유저가 해당 파일 또는 디렉토리에 대
해 얼마만큼 접근 권한을 가질지 설정, 권한은 3가지 읽(r)기, 쓰기(w) , 실행(e)



파일 및 디렉토리 권한

첫번쨰열 drwxrwxr-x 권한 플래그

4가지로 나뉨 d rwx rwx r-x

가장 첫글자는 파일 타입 -> d는 디렉토리, -는 일반 파일, l은 바로가기와 같은 링크파일

두번쨰 세글자 rwx는 파일또는 디렉토리 소유자의 권한, 세번쨰 세글자 rwx는 소유그룹에 포함된 유저들의 권
한

마지막 r-x 는 이둘을 제외한 나머지 유저 권한

세번쨰 열 user  파일또는 디렉토리 소유자 네번째열 user - 소유그룹



파일 및 디렉토리 권한 명령어 

chmod - 파일권한 변경 명령어, root유저 혹은 파일 소유자만 실행가능, chmod 권한 파일명 형식으로 사용, 
권한 표현할떄 권한 플래그를 10진수로 표현하거나 기존권한에 문자 더하거나 뻄.

chown - 파일소유자 혹은 소유 그룹을 변경하는 명령어, root유만 실행가능, chown 사용자명[.그룹명] 파일
명 형식, 소유그룹만 변경하고 싶은 경우 chgrp사용

유저레벨이며 커널레벨은 일반 사용자가 조작불가, 사용자가 운영체제를 온전히 사용하기 위해서는 커널과 유
저를 이을 연결프로그램 필요 ,이를 셀이라 부름,

bash - sh를 대체하기 위한 유닉스 셸, 일반 사용자가 로그인하면 볼수있는 셸이 bash,sh의 기능을 더해 다음
내용 추가지원, 명령 히스토리, tab 자동완성, bash로그인시 아래 시작파일 자동 실행

ash /dash - bash보다 경량화된 유닉스 셸, 라이브러리 의존성이 상대적 적음, 플로피디스크에 셸 설치, 루트

사용자 셸, /bin/sh 대체용으로 사용

zsh - sh가반으로 bash,ksh등 다양한 셸 장점 모아 만든 확장형 셸, 커스텀 용이 설치 간편

프로세스 생성 및 관리

프로세스란 컴퓨터에서 실행되고있는 프로그램, cpu에서 실행 여러 프로세스 동시실행시 운영체제가 순서조절

5가지 생성, 실행, 준비, 대기, 종료단계를 가짐.

리눅스프로세스는 pid와 ppid를 가짐, pid는 현재 프로세스 아이디, ppid는 부모프로세스의id, 아이디는 고유
함.

프로세스 관리

프로세스 확인(ps,htop) - 현재 실행중인 프로세스 상태를 보여줌 ps 옵션

포그라운드와 백그라운드(fg,bg,jobs) - 프그라운드는 사용자와 직적 상호작용, 입력등 직접적 작용 / 백그라
운드 직접적 상호작용하지않음, 백그라운드에 있지만 실행되지않는경우 정지되어있다 표현

프로그램 종료(kill,pkill) - 프로그램종료는 kill명령어 사용, 시그널이란 커널에 프로세스에 보내는특수 신
호, 받는즉시 우선적처리

프로그램 우선 순위(nice) - 우선순위를 결정, 숫자낮을수록 우선순위 높고 설정안할시 기본값 0 증가만 가능

프로세스 모니터링(htop) - 프로세스를 모니터링 하기 위해 사용하는 top을 개량, gul처럼 사용가능



환경변수

환경변수란 컴퓨터에서 실행중인 프로세스의 동작 방식에 영향을 미치는 값, 사용자 임의 정의 ,키-값 쌍의 형
태 시스템 및 프로그램 성정이나 동작 필요정보 전달

환경변수 확인(env) - 현재 환경변수 출력및 새로운 환경변수 설정후 실행할떄 사용

환경변수 설정(export)- 셸에서 새로운 환경변수 생성할떄 사용

환경변수 삭제(unset) - 설정 해제를 의미함, 이전에 생성한 환경변수 삭제 가능

사용자와 그룹

리눅스는 유저와 그룹을 가짐, 한 유저가 여러개의 유저권한 가질수없고 그룹은 특정권한가진 사용자 집단을 
표현, 한유저는 여러개의 그룹에 속할수있음.

리눅스 파일 권한 - 소유자 그룹, 일반사용자 주체 각각에 대해 읽기, 쓰기, 실행 3가지 권한 부여 , 9가지의 
조합 각권한 모두 독립적이며 동시에 가질수있음.

유저생성 (useradd,adduser) - 새로운 유저 생성, root만 가능

유저관리(usermod, passwd) - 유저정보 변경, root만 가능

유저삭제(userdel,deluser) - 유저를 제거

그룹생성(groupadd,addgroup) - 새로운 그룹 생성, root만 기능

그룹정보변경(groupmod) - 그룹정보 변경, root만 가능

그룹 관리(groupwd) - 그룹관리, root만 가능 

유저삭제(groupdel,delgroup) - 그룹를 제거

그룹 변경(chgrp) - 폴더나 디렉토리 그룹을 변경할떄 사용

소유자,그룹 변경(chown) - 폴더나 디렉토리 소유자와 소유그룹을 변경할 때 사용

권한변경(chmod) - 파일권한 변경

유저변경(su) - 다른 유저로의 전환을 위해 사용, 지정안하면 root의미

유저 변경 및 실행(sudo) - 현재계정에서 다른계정의 권한을 빌려 명령 수행, 지정안하면 root권한 실핼
