apt 패키지 관리

apt& apt-get apt-get이 먼저 만들어졌으며 apt는 apt-get이 가지는 단점 해결하기 위해 등장

apt-get은 패키지의 설치,업데이트 삭제만 가능, 설치가능 패키지 조회는 apt-cache, 시스템에 설치된 패키지 조회는 dpkg -l 이기능통합 위해 apt등장, 정밀성은 apt-get, 편의성은 apt , root에서만 사용가능


네트워크란 그물 + 일의 합성어로 2개이상의 컴퓨터들이 서로 통신하기위해 필요한 모든것을 통칭, 프로토콜이라 부르기도 하며 tcp/ip 프로토콜을 많이 사용(os 7계층) 응용,표현,세션,전송,네트워크계층, 데이터링크,물리계층으로 이루어져있음

네트워크 인터페이스는 컴퓨터나 네트워크 장비가 통신을 하기위한 물리적 가상의 연결지점, 네트워크 인터페이스 카드가 존재, lan혹은 wifi에서 받은 전기신호를 디지털 데이터 변환, 가상머신등을 사용하면 가상 랜카드 생성

네트워크 접속(nc) - tcp 혹은 udp연결을 읽거나 기록하는 프로그램 , 사용자는 nc를 이용하며 tcp혹은 udp를 지원한느 네트워크환경에 접속

네트워크 접속(ssh) - 텔넷이 암호화를 지원하지않아 이를 보완하기 위해 나온 프로토콜, 22번에 할당, 디피 - 헬만 키 교환 방식사용

파일다운로드(wget) - 웹상의 파일 다운로드 받기위한 명령어, http, https , ftp 프로토콜을 사용하는 사이트의 파일 다운로드가능

네트워크 데이터 전송(curl) - 특정프로토콜을 이용해 url로 데이터 전송, 서버에 데이터를 보내거나 가져올떄 사용, 다양한 프로토콜 지원



편집기 - 문저편집기는 문서파일을 편집하기 위해 쓰이는 소프트웨어

vi,vim -  vi는 현대에 가장많이 사용되는 편집기인 vim,neovim등의 모태가 되는 가장 기본적이면서 필요한 기능 모두 포함.

vim - vi 개량형, 명령모드와 편집모드 2가지를 가짐, 프로그램 실행시 명령모드, 명령모드에서 명령을 내려 편집모드로 들어갈수 있음.

vim 편집 - vim를 입력해 편집기로 들어온후 a를 입력하면 편집모드로 들어갈수있음.

vim 커서 이동 - 커서는 문서 맨아래, gg를 입력시 커서가 맨위로 올라감,1칸씩이동은 화살표를 이용

vim 복사 - 해당줄에서 yy를 누른후 p를 누르면 동일한 줄이 복사된후 븥여넣기됨.

vim 검색 - 명령모드에서 .hello를 입력시 입력부분이 하이라이트 표시

vim 저장 - :w를 입력시 파일 이름 지정되지않았았다고 뜨며 :w 파일이름을 지정시 정상적 파일저장가능
